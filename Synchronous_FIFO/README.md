# Synchronous FIFO

## Description
This project implements a Synchronous FIFO using Verilog HDL in Xilinx Vivado.

## Features
- Synchronous Read and Write
- Full and Empty Flag Generation
- Verilog HDL Implementation
- Tested using a Verilog Testbench

## Tools Used
- Xilinx Vivado
- Verilog HDL

## Project Files
- FIFO.v
- FIFO_tb.v
